AWS DevOps Infrastructure Using Jenkins

Designed and provisioned a three-tier AWS infrastructure using Terraform and Jenkins. The architecture includes a public Network Load Balancer, a web tier using EC2 Auto Scaling, an internal load balancer, a private application tier and an Amazon RDS MySQL database. Integrated remote Terraform state and locking, IAM, CloudWatch monitoring, SNS notifications and AWS Backup.
